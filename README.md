# DSA

Collection of Data Structures & Algorithms implementations in C.

## Contents

### 🔹 Patterns
22+ pattern-printing programs covering number, star, and pyramid patterns.

### 🔹 Linked List
All 4 types implemented with core operations:
- Singly Linked List
- Doubly Linked List
- Circular Linked List
- Circular Doubly Linked List

Operations covered: Insertion, Deletion, Reversal, Traversal.

### 🔹 Stack
Stack implementation and operations (push, pop, peek, etc.).

### 🔹 Coming soon

- Trees (Binary Tree, BST, etc.)
- Graphs
